# 📊 US Sales Analysis Dashboard – Power BI

## 📌 Project Overview

This project presents an interactive Power BI dashboard designed to analyze US sales performance.

The dashboard provides insights into sales performance across different regions, sales channels, warehouses, and time periods.

## 🛠️ Tools & Technologies

- Power BI
- Power Query
- DAX
- Data Cleaning
- Data Modeling
- Data Visualization

## 📈 Key KPIs

- 💰 Completed Sales: $3.4M
- 📦 Total Units Sold: 83K
- 🧾 Unique Orders: 2,470
- 💵 Average Sales per Day: $1,378

## 🔍 Dashboard Analysis

### Sales by Channel
Analyzed sales distribution across:
- Online
- Wholesale
- Distributor
- Club

### Sales by Warehouse
Compared sales performance across different warehouses.

### Sales by Region
Analyzed sales across major US regions and states using an interactive map.

### Sales Trend
Visualized completed sales over time to identify daily and monthly sales patterns.

## 🎛️ Interactive Filters

The dashboard includes filters for:

- Year
- Month
- Sales period

These filters allow users to interactively explore sales performance.
